# 📝 Next.js Task Manager

A simple and clean **Task Manager application** built using **React.js and Next.js**.

This project allows users to create tasks with a title and description, view all added tasks, and delete tasks when they are no longer needed.

---

## 🚀 Features

- ➕ Add new tasks
- 📝 Add task title and description
- 📋 Display all available tasks
- 🗑️ Delete tasks
- ⚛️ Built with React.js
- ▲ Built using Next.js
- 🎨 Styled with Tailwind CSS
- 🧩 Reusable React components
- 📱 Responsive user interface

---

## 🛠️ Tech Stack

- **Next.js**
- **React.js**
- **JavaScript**
- **Tailwind CSS**
- **HTML5**
- **CSS3**
